# @tsonic/js-globals

Retired package.

JS projects now use the first-party `@tsonic/js` surface directly. Do not use `@tsonic/js-globals` for new work.

## Usage

Use `@tsonic/js` instead:

```bash
npx --yes tsonic@latest init --surface @tsonic/js
```

`@tsonic/js` now owns:

- JS ambient globals
- JS built-in APIs
- source-level runtime behavior
